# Email pictures

- `dud/`: pictures for a starter who scored 0 or less (an ice)
- `lowest/`: pictures for the lowest score of the week (an ice)
- `highest/`: pictures for the highest score of the week (a congratulations, not an ice)

Use JPG, PNG, GIF or WebP files, ideally under 2 MB each. If a folder has more than one picture, each
email picks one at random. Add, remove or swap files at any time; the next refresh uses whatever is here.

These are published with the site, so keep them small: about 960 pixels wide is plenty. Full-size
originals can go in `notify-images-originals/`, which isn't published or committed.
